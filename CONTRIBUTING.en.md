# How to Contribute to GTunnel

First off, thank you for considering contributing to GTunnel! Whether it's reporting a bug, suggesting an enhancement, or submitting code, your help is greatly appreciated.

## How Can I Contribute?

### Reporting Bugs

If you find a bug in the project, please report it by opening an issue on [GitHub Issues](https://github.com/LayorX/GTunnel/issues). When submitting a bug report, please include the following details:

-   Your operating system and Python version.
-   Detailed steps to reproduce the bug.
-   What you expected to happen.
-   What actually happened (including full error messages and logs).

### Suggesting Enhancements

If you have an idea for a new feature or an improvement, feel free to suggest it via [GitHub Issues](https://github.com/LayorX/GTunnel/issues). Please describe the feature and the problem it solves clearly.

### Pull Requests

We warmly welcome code contributions via Pull Requests (PRs).

1.  **Fork the repository**: Click the "Fork" button in the top-right corner of the page.

2.  **Create your feature branch**:
    ```bash
    git checkout -b feature/YourAmazingFeature
    ```

3.  **Commit your changes**:
    ```bash
    git commit -m 'feat: Add some AmazingFeature'
    ```
    *(Please follow the [Conventional Commits](https://www.conventionalcommits.org/) format for your commit messages, as it helps us understand the nature of the change.)*

4.  **Push your branch to your fork**:
    ```bash
    git push origin feature/YourAmazingFeature
    ```

5.  **Open a new Pull Request**: Return to the project's GitHub page and click the "New pull request" button.

## Code Style

-   This project follows the [PEP 8](https://www.python.org/dev/peps/pep-0008/) style guide for Python code.
-   Please ensure your code is well-commented, especially in logically complex areas.

Thank you again for your contribution!
